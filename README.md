# dc4_fd_chineseization

《D.C.4 - Fortunate Departures -》汉化工程。

## 当前状态

当前仅初始化项目骨架，尚无可执行的解包、回写或构建链。`main_key.py`、`main_unpack.py`、`main_build.py` 尚未实现。

只读初查已确认原版主程序使用 KiriKiri Z，架构为 x86，EXE 核心版本为 `1.2.0.3`，资源分布于 5 个 XP3。XP3 目录索引可读；`data.xp3` 索引包含 215 个 `.ks.scn`、30 个 `.ks`、248 个 `.tjs` 和 23 个 `.pimg`。这些是目录信息，资源负载尚未解密，详见 `docs/game_baseline.json`。

负载解密方案、SCN 内部格式、文本编码与控制结构、可编辑回写、中文显示、补丁加载方式及签名是否强制校验均待验证。

## 目录

| 路径 | 用途 |
| --- | --- |
| `game/` | 本地原版副本，复制时排除现存 `savedata/`，不提交 |
| `game_script/raw_script/` | 正式日文文本基线 |
| `game_script/translated_script/scn/` | 正式可编辑译文输入 |
| `solution/decrypt/` | 经本作验证的解密实现与参数 |
| `solution/unpack/` | 封包读取、脚本解析与文本导出实现 |
| `solution/build/` | 脚本回写、封包重建、构建与验证实现 |
| `solution/runtime/` | 所需运行时补丁的源码与构建入口 |
| `solution/patch/base/chs_patch/` | 维护的静态补丁资源 |
| `solution/patch/base/chs_patch_manifest.txt` | 静态资源进包清单，当前为空 |
| `docs/` | 原版基线、格式和维护文档 |
| `tmp/` | 解包、调查和验证的中间产物，不提交 |
| `out/` | 生成的验证包与发布包，不提交 |

维护流程以项目根目录为基准使用相对路径。游戏、工具缓存、生成物与维护源码分开保存。

## 后续顺序

1. 验证本作 XP3 负载读取方式，并确认 SCN 格式、文本编码和控制结构。
2. 实现文本导出与回写，验证原文回环及修改文本后的长度、偏移和表结构。
3. 实现补丁包重建，重新读取并比较脚本与资源。
4. 确认补丁加载、字体与编码策略；如需运行时 EXE 或 DLL，从源码构建并保留来源。
5. 验证中文显示、存档行为和实际游戏加载，再固定完整构建与发布流程。

依赖版本和可执行命令随工具的真实实现补充。文本增量更新将从正式译文输入开始；静态资源增量更新将从静态资源目录与清单开始。两条路径均须经过对应回写、重建和加载验证，目前尚不可执行。
